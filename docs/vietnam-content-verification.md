## Подтверждённые недостатки и исправления

- Пустой endpoint и mailto вместо server acceptance; README описывал старый сценарий. Добавлены Pages Function, клиентский протокол подтверждения, честная проверка доступности и прямые контакты.
- Inline форма страны не передавала country. Исправлено.
- contact-submit содержал персональные данные в CustomEvent. Заменён событиями open / attempt / success / error без персональных полей и без URL query.
- Телефон в диалоге имел иконку WhatsApp. Теперь иконка соответствует действию, в том числе после смены страны.
- Ссылка Tripadvisor ведёт на Dahab, что видно и на старом сайте. Удалена только из вьетнамской навигации и sameAs этого раздела; локальная карточка не выдумана.
- Галерея Вьетнама вела на /media/dahab/. Исправлена на существующую /media/vietnam/ без изменения композиции.
- Страница сёрфинга не содержала Малибу и форматов 1 час / 1,5 часа. Добавлено; ветровой календарь убран только со страницы классического сёрфинга.
- Прокат и хранение расходились с опубликованным источником. Новый прайс обновлён полностью, включая страховку; суммы сверены с живой DOM старой страницы, а не только поисковым кешем.
- Title / description спорта были общими для стран; добавлены вьетнамские метаданные и изображения. Canonical уже соответствовал будущему основному домену — сохранён. Исправлена последняя крошка .php статей.
- Новой страницы дороги не было. Добавлена /vietnam/how-to-get/, использованы стабильные сведения без старых расписаний/цен трансфера.
